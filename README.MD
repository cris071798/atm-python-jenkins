# ATM Python Jenkins

Proyecto de Integración Continua desarrollado para la materia de DevOps.

## Descripción

Aplicación de cajero automático (ATM) desarrollada en Python que permite consultar saldo, realizar depósitos y retiros.

El proyecto incluye pruebas unitarias que serán ejecutadas automáticamente mediante un Pipeline de Jenkins.

## Tecnologías utilizadas

- Python
- Git
- GitHub
- Jenkins
- AWS EC2
